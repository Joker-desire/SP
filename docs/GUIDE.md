## 1. 五分钟跑通一遍

**第一步：选文件夹。** 点顶栏「选择文件夹」，或直接把文件夹拖进窗口。如果里面有子文件夹，会先弹一张勾选表问你要扫哪些（默认全选＝连子目录一起扫）；没有子文件夹就直接开扫，**边扫边出图**，不用等进度条走完。

**第二步：看图标记。** 顶栏「分组依据」先选个维度（按拍摄日期最常用）。**双击**任意卡片进大图（单击只是选中，选中后按回车或空格也能进）。然后只用三根手指：

- `P` 保留 → 自动跳下一张
- `X` 淘汰 → 自动跳下一张
- `0`–`5` 打星（`0` 是清除）

标错了按 `⌘Z`（Windows 是 `Ctrl+Z`）退回去，最多 50 步。

**第三步：导出。** 网格上方「批量 ▾」可以先对筛选结果整批标记；点「导出…」把挑中的照片**复制**到你指定目录——面板里能选「当前选中的 / 保留的 / 淘汰的 / 全部已标记 / 当前筛选下的全部照片」，可以只要 RAW 或只要 JPG，并附一份 CSV 清单。**原片一张都不会被动**。

关窗口只是收进托盘，不是退出——见常见问题「关了窗口去哪找 / 怎么彻底退出」。

## 2. 按场景找路

先查表，再翻对应小节。

| 我想…… | 去哪 |
|---|---|
| 把明显糊了、曝错的先挑出来扔掉 | [侧栏「画面质量」](#场景一把废片先挑掉) → 「批量 ▾」标为淘汰 |
| 连拍十几张里挑一张 | [顶栏「连拍」](#7-连拍对比) → `Shift` + 点击 |
| 挑竖图发社交媒体 | [侧栏「画幅方向」](#场景三挑竖图发社交媒体) |
| 只看某天 / 某支镜头 / 某档 ISO | [左侧筛选栏](#6-筛选与侧栏)，同维并集、跨维交集 |
| 把照片分成「要修 / 要发 / 给客户」三批 | [色标](#8-色标给照片分批次) `6`–`9` / `-` |
| 确认某张有没有真的对上焦 | 大图里 `A` 切 1:1，或 `O` 看对焦点 |
| 判断是不是过曝了 | 大图里 `H` 看[直方图](#5-看图与标记) |
| 跟同一批的下半场，只要新拷进来的 | 启动时自动增量扫描，不用管；也可点「重新扫描」 |
| 界面按钮太多，只想留常用的 | [功能页](#11-让界面只剩你要的按钮) →「简洁」 |
| 导出后进 Lightroom 接着修 | [导出](#9-导出)，CSV 里带着星级与去留 |
| 清理缓存腾空间 | 页脚右下角占用数字 / 顶栏「清理」 |

### 场景一：把废片先挑掉

拍完先做一轮粗筛，比一张张看快得多：

1. 导入后不用等——后台分析会在网格铺出来之后自己跑，页脚最后提示「画面分析完成（N 张）」。侧栏「画面质量」三项计数开始出现，就说明有结果了。
2. 点「疑似跑焦」——网格只剩这一批。点「疑似过曝」「疑似欠曝」同理，可以多选。
3. 抽几张进大图复核：跑焦的按 `A` 切 1:1 看眼睛/主体是否实；曝光的按 `H` 看直方图两端有没有堆死。
4. 然后二选一：
   - **信任初筛**（这批片子本来就要得不多）：直接「批量 ▾」→「标为淘汰」，一次筛过的全扔掉。
   - **逐张复核**：`P` 留、`X` 扔，标完自动过片；标错的 `⌘Z` 退。

> 徽标一律写「**疑似**」——机器初筛，雪景、白墙、逆光天空都可能看错。把它当成「优先看这几张」的提示，别当地判决。批量标记会**覆盖**这一批已有的去留，所以别一边 `P` 一边批量淘汰——两条路径选一条。

### 场景二：连拍里只留一张

1. 顶栏「连拍」，先选「相隔多久算一组」——1 / 3 / 10 秒，默认 3 秒。下面按组列出所有连拍。
2. 点某一组的「对比挑选」进对比网格，`Shift` + 点击某张＝只留这张、同组其余全淘汰；也可以 `Shift` + `1`–`9` 直接选第几张。
3. 不是每张都必须二选一——同一组**可以保留多张**，普通点击只是切换单张状态（想两张都留就都点成保留）。
4. `Esc` 退出，回到普通网格。

### 场景三：挑竖图发社交媒体

1. 侧栏「画幅方向」→ 勾「竖图」。横拍、方图、尺寸未知都会被排除。
2. 工具栏把列数调到 1–2 列（`−` `+`），缩略图会自动请求更高分辨率那一档，看构图更准。
3. 逐张打星，4–5 星给要发的。
4. 侧栏「星级」勾 4 星 + 5 星，点「导出…」→「导出哪些」选「当前筛选下的全部照片」。

### 场景四：一批照片分几种用途

同一批照片里，「要精修的」「要发朋友圈的」「要给客户选片的」经常重叠，星级不够用。用色标当第二条轴：

1. `6` `7` `8` `9` `-` 分别是红 / 黄 / 绿 / 蓝 / 紫，颜色什么意思你自己定（比如红＝要修、绿＝可直接发）。
2. 侧栏按颜色筛，导出时分别导一次。
3. 色标和星级、去留完全独立：标颜色不会改星级，清色标也不会误删评分。

### 场景五：同一批照片分了两次拍

第二次开机把新照片拷进同一个文件夹，直接打开 S·P：

- 它会自动恢复上次的图库，先用已有索引把网格铺出来，再在后台比「文件大小 + 修改时间」找出新文件并入库。
- 界面不会因为你补了照片就整个重排（标记、筛选、滚动位置都还在）。
- 想强制重来一遍就点「重新扫描」，范围和上次一致。

### 场景六：找一张记得名字的照片

搜索框支持文件名片段，可以和侧栏条件叠加。比如「11 月 8 日 + 180-600 镜头 + 文件名里带 DSC_04」。

所有生效中的条件都会变成已选条件区的一枚 chip，点 chip 单独摘掉，旁边「全部清除」一次清空（工具栏「清除筛选（N）」同效）——不用担心筛完找不到出口。

## 4. 导入与扫描

**拖进来也行**：把照片文件夹直接拖进窗口，松开就开始扫描；拖一张 JPG / NEF 照片进来会导入它**所在的文件夹**。拖入时窗口出现蓝色虚线提示层，其它文件（txt、快捷方式、压缩包等）会被拒绝。有子文件夹时同样先问一次范围，跟点「选择文件夹」完全一致；一次拖入多个文件夹只采用第一个。扫描进行中或范围弹窗未关时，会提示等这一轮结束，不会把图库切到一半。

**选文件夹时会先问范围**：如果里面还有子文件夹，会弹出一张勾选表——默认全选，即整目录递归；只想看这个文件夹自己的照片就**一个都不勾**（只读这一层、不进子文件夹）；只要某几个子目录就只勾它们。勾选结果会记住，之后点「重扫」沿用同一范围。没有子文件夹时不弹表，直接扫。

> 已知取舍：勾了子目录就**不包含根目录自己那一层**的照片——要么都不勾（只看这一层），要么全勾（递归）。混着来需要给每个目录各配一个扫描层数，弹窗里加一行「（当前文件夹里的照片）」勾选项即可。

**选完即扫，边扫边出图**：入库按批次提交并每批释放数据库连接锁，网格先铺出已入库的前 N 张，过程中可以照常滚动与标记。启动时自动恢复上次的图库，先用已有索引铺图，再后台增量重扫；文件没动过就不重排界面（不闪）。

**顶栏「清空」**回到未选文件夹的状态：不删原片、不碰索引库，选片标记也原样留着，重扫同一个文件夹会自动回到照片上。

**换文件夹不会串台**：旧文件夹的照片会故意留在库里（为了标记能复用），但界面只显示当前文件夹范围内的照片，导出和左侧计数同理。

**主区是分组视图**：照片按顶栏「分组依据」下拉选的维度收组（组名吸顶、可折叠）。文件夹、选片状态、星级、文件类型、拍摄日期、机身、画面质量、镜头、焦段、ISO、画幅方向（横 / 竖 / 方 / 未知）都能当依据；文件夹分组显示相对路径，子文件夹自带母文件夹。单击卡片＝选中（可以连续多选、`Shift` 选一段），**双击**进单张大图看细节、按 `P`/`X` 标去留。

**按错了直接撤销**：`⌘Z` / `Ctrl+Z`（或顶栏「撤销」）一步步退回，`⇧⌘Z` 再往前一步，最多各 50 步；批量标记和连拍里一次改一组也是一次退干净。撤销走的是和正向标记同一条写库路径，侧栏计数、筛选、导出全都跟着动。

## 5. 看图与标记

**双击**卡片进单张大图（单击是选中），`←` `→` 翻页、`Esc` 关闭，里面同样能标记与打星。

**网格里也能直接标，不用先点选**：鼠标停在哪张卡片上，按 `P` / `X` / `U` / `1`–`5` / 色标键就作用于那张；悬停时卡片浮出 5 颗可点的星和 `0`（清除），点一下即写库、`⌘Z` 可撤销。选中两张以上时以「选中的那批」为准，免得鼠标随手一放把批量标记变成单张。当前目标有一圈细边框，和「选中」的外描边叠在一起也能分清。

- **缩放**：滚轮（以鼠标为锚点）、双击切换、放大后拖拽平移，`+` `-` 缩放、`⇧F` 复位、`A` 到 1:1、`F` 全屏；右上角控件条显示当前倍率。`1:1` 是一个图像素占一个屏幕像素——判断有没有对上焦就用它。放大超过 1 倍才去生成 4096px 那档，**倍率和平移不变，只是变清晰**；翻页自动回到整图。
- **详情面板**（`I` 或「详情」按钮，默认收起不挡照片）：文件属性（长路径点击即复制）、**完整 EXIF**（打开时现读原文件，枚举值译中文：曝光程序 / 补偿 / 测光 / 闪光灯、镜头型号与序列号 / 等效焦距、机身序列号 / 固件、色彩空间 / 白平衡、时间与时区、GPS 坐标与海拔、描述 / 作者 / 版权 / 备注）、画面分析分数、同组 NEF/JPG 文件（标注原文件是否还在）。
- **对焦框**（`O` 键或「对焦点」按钮，**默认关**）：把相机按快门时真正用上的那一块画在大图上，缩放时跟着走。数据来自尼康 MakerNote 的 AFInfo2，是传感器原始像素坐标；读不到（非尼康 / 机身没写）就不画、不报错。其他机身目前读不出来，各家 MakerNote 格式各异。
- **直方图**（`H` 键或底栏「直方图」，**默认收起**）：左上角面板画 RGB 三条曲线 + 亮度填充，四等分参考线方便看两端堆积。曲线贴最右＝高光溢出，贴最左＝暗部死黑；比「疑似过曝」四个字更能自己下判断。数据取自内嵌预览、翻页自动跟着换，开关状态会记住；面板固定在左上、详情面板在右侧，两者同时开也不挡。简洁模式下这个按钮同样保留。
- **分页加载 + 视口外卸载位图**：滚到哪读到哪，滚出 2400px 的卡片把解码后的位图还给系统（数据 URL 仍在内存缓存里，回来时秒恢复），几千张不会撑爆内存。

## 6. 筛选与侧栏

左侧筛选栏覆盖：选片状态 / 星级 / 色标 / 画面质量 / 文件类型 / 画幅方向 / 拍摄日期（按月份分组）/ 焦段 / ISO / 机身 / 镜头 / 文件名搜索，以及八种排序（拍摄时间正逆、文件名正逆、星级高低、清晰度两向、文件大小），每一项都带图库范围内的计数。

- **多选**：同一维里可以勾好几个值（两支镜头、好几天、几档 ISO…），**同维取并集、跨维取交集**（「11 月 8 日 + 保留 + 180-600」）；再点一次已选项＝取消，点「全部」＝清空这一维，不用专门跑去找「全部」那一项。
- **已选条件区**：每个选中的值一枚 chip，带维度名、点一下单独摘掉，旁边「全部清除」一次清空（工具栏「清除筛选」同效）。选得多时列表内滚动并做底部渐隐，长镜头名折两行不被截断。
- **两层折叠**：点顶部「筛选」把手（或按 `\`）把整栏收成 44px 窄轨，网格自动变宽；窄轨上的数字徽标是生效中的筛选条件数。每个分面组标题也能单独折叠（键盘 `Enter` / 空格同样可用）。两个状态都记在 localStorage，重启保持；有筛选生效的那一栏会自动展开。
- **计数口径**：是**整个图库**，不是「在当前结果里再数一遍」。这样点开侧栏看到的数字始终稳定，不会因为叠加条件而缩水到看不懂。
- **镜头栏只要有照片就在**：标题显示当前图库有几支镜头，超过 6 支先收起尾巴，点「显示全部」摊开，选中的镜头自动展开到可见；读不到镜头型号的照片归到「未知镜头」，也能单独筛掉。
- **拍摄日期按月份折叠**，默认只展开最近两个月——几百天全铺开会翻到崩溃。筛选到某个日期时，它所在的月份会自动展开。
- **机身时间偏移校正**：侧栏「机身」标题后的「时间校正」，多机身时钟不同步时给快的那台填负数，排序与连拍分组立刻按校正后的时间重算（只在读到两台以上机身时出现）。
- **画面质量**（自动判断）：扫描之后后台分析每张的清晰度与曝光，结果进侧栏与网格徽标——鼠标悬停在徽标上能看到具体数值。**看的是画面里最清晰的那一块，不是全图**，所以浅景深、背景虚化的照片不会被误判。徽标写的是「疑似跑焦」「疑似过曝」「疑似欠曝」：机器初筛，白墙、雪景、逆光天空都可能看错，以肉眼和直方图为准。算法细节见 [`INTERNALS.md`](INTERNALS.md) 第 4 节。
- **画幅方向**：横图 / 竖图 / 方图 / 尺寸未知四档，可多选；顶栏「分组依据」也能选「按横竖图分组」。判定用扫描时记下的像素宽高，并按 EXIF 旋转标记把竖拍的宽高对调。**尼康 NEF 常把尺寸写在读不到的位置**，这时退化看旋转标记判横竖，所以竖拍 NEF 仍会归到「竖图」；两个都读不到的照片才归「尺寸未知」。

**批量标记**：网格上方「批量 ▾」对**当前筛选出来的全部照片**（含还没滚出来的那些）一次性标保留 / 淘汰 / 清除 / 打星——比如「ISO 6400 以上全标淘汰」不用一张张点，一次 `⌘Z` 整批退回。

**选片进度**：页脚显示「已过目 312 / 1000（31%）· 保留 48」。口径是当前文件夹的**全部**照片，不跟着筛选变；打了星也算过目。

## 7. 连拍对比

按拍摄时间间隔自动把连拍聚成组（1 / 3 / 10 秒可调，默认 3 秒；入口在顶栏「连拍」）。

- 对比网格里点一张只切换这一张，**同一组可以保留多张**
- `Shift` + 点击（或 `Shift` + `1`–`9`）＝只留这张、其余淘汰
- 「清空本组」一键回到未标记，`Esc` 退出
- 顶部实时显示「已保留 N 张」，导出按 `decision` 筛选，同组多张保留会全部导出

跨机身拍同一个场景时，先把[机身时间偏移](#6-筛选与侧栏)校好，几何分组才不会错开。

## 8. 色标：给照片分批次

保留 / 星级之外的第三条轴。同一批照片里「要修的」「要发的」「给客户看的」常常重叠，星级一旦被拿去表示去留，就再也腾不出手表达批次——色标颜色本身不表意，你定它是什么意思。

- 键位：`6` `7` `8` `9` 分别是红 / 黄 / 绿 / 蓝，**减号 `-` 是紫**（`0` 已是清除星级、`1`-`5` 是星级，第五个色没有数字可用，就挂在它在键盘上的邻居身上）；再按一次同一个键＝取消。大图底栏有五个色点，卡片左边一条竖色带，侧栏可按颜色筛、详情面板显示当前色。
- **和星级、去留完全独立**：标红色不动决策也不动星级，`⌘Z` 一步退掉整批，清色标不会误删评分。老库升级不用做任何事，色标列会自动补上。

## 9. 导出

点网格上方「导出…」。面板三段选择：

| 选项 | 可取值 |
|---|---|
| **导出哪些** | 当前选中的 / 保留的 / 淘汰的 / 全部已标记 / 当前筛选下的全部照片 |
| **怎么导出** | 复制原文件到目标文件夹 · 只生成清单 CSV（不复制文件） |
| **要哪些文件** | RAW + JPG / 仅 RAW / 仅 JPG |

**文件名**可用变量拼：`{name}` 原文件名 · `{date}` 拍摄日期 · `{time}` 时间 · `{seq}` 序号 · `{stars}` 星级 · `{camera}` 机身 · `{pair}` 配对键。重名自动加后缀，同大小文件跳过。

导出还会**顺手生成一份带 BOM 的 CSV 清单**（Excel 直接打开不乱码），每张照片的去留、星级、色标、路径都在里面。**只读原片，绝不删除、移动或重命名。**

「淘汰的」也能导——把否掉的片子单独导出来给别人复核，或者自己隔天再筛一遍，都用得上。真删文件要你自己动手，S·P 不碰。

## 10. 缓存与清理

**缩略图缓存会一直长大**，页脚右下角实时显示占用（缩略图 + 索引库合计）。放大查看过的照片还会多一份 4096px 高清档，是增长最快的一项。

点占用数字、或顶栏「清理」，打开三档清理面板：

| 档位 | 清掉什么 | 代价 |
|---|---|---|
| 只清缩略图 | 磁盘上的图片缓存 | 最安全，下次看再生成 |
| 连索引一起清 | 照片索引 + 缓存 | **选片标记保留**，重扫后自动回到照片上 |
| 全部清空 | 保留 / 淘汰、星级、色标一起删 | 不可恢复 |

缓存另有 2GB 水位线自动 LRU 淘汰。全程不碰原片。

## 11. 让界面只剩你要的按钮

顶栏右侧那颗按钮显示当前档位（「简洁」或「专业」），点它或按 `⌘/Ctrl + ,` 打开功能页。

- **34 个可开关的控件**按「顶栏与文件 / 选片操作 / 左侧筛选 / 大图查看」分组列出，勾上就显示、取消就藏起来——背后就是真实界面，所见即所得。
- **「简洁」「专业」只是这页里的两组预设按钮**，改任何一项就变成「自定义」。全新安装默认简洁，已有图库的老用户升级后保持专业。
- **只改可见性**：不换界面逻辑、不清筛选 / 选择 / 分组。被藏起来的功能**快捷键照常可用**（`P`/`X`/`U`、`1`–`5`、`I`、`H`、`F`…）。
- **选择文件夹、导出、清除筛选、关于 / 更新入口始终显示**，避免把自己关在外面。筛选一旦生效，「清除筛选（N）」常显。
- 底部「恢复推荐」回到预设，「完成」关掉面板。

**简洁档另外会**：默认 2 列、侧栏收成窄轨。两种档位各自记住自己的列数与侧栏状态。

**首次启动会弹一屏键位卡**（只出现一次），看完点「知道了，开始选片」。

**自定义列数**：工具栏 `− / 当前列数 / +`，点中间那颗回到「自动」（按窗口宽度排）；范围 1–8 列，网格里 `[` `]` 也能调。两种界面档位各记各的列数。1 列时缩略图自动改请求 1600px 档，不会被 512px 拉糊。

## 14. 常见问题

**macOS 双击提示「应用已损坏，无法打开」**：应用只有 ad-hoc 签名，从浏览器下载的文件带隔离属性，右键 → 打开也不管用。拖进「应用程序」后执行：

```bash
xattr -cr "/Applications/S·P.app"
```

Windows 同理会有 SmartScreen 提示，点「仍要运行」。

**检查更新 / 下载更新包失败**：v0.4.3 起面板会显示分类后的中文原因（网络被网关拦截、验签失败、无权限替换 app、其它）并附原始错误摘要。已知本机到 `github.com/.../releases/download/` 的大文件会返回 `504 Gateway Time-out`，清单能取到但更新包下不动——产物本身无损，直接从 [Releases](https://github.com/Joker-desire/SP/releases) 手动装对应 dmg / msi 即可。排查过程见 [`AUTO_UPDATE.md`](AUTO_UPDATE.md) 第 6 节。

**窗口被挡住时缩略图几乎不加载**：WebKit 会暂停后台渲染，那是浏览器省电策略，不是卡住。切回前台就恢复。

**「疑似跑焦 / 疑似过曝」标得不准**：三项都是后台机器初筛，不是结论。清晰度只看画面里最清晰的那一块（虚化背景不会把锐利主体拉低），高光溢出看近纯白像素是不是占了一大片；白墙、雪景、逆光天空仍可能被误标。到大图按 `H` 打开直方图看两端有没有堆积，以肉眼为准——徽标只是提示「优先复核这几张」。算法升级后旧图库的指标会在下次启动时自动重算，不用手动清缓存或点重扫。

**「尺寸未知」是什么 / 方图为什么没单独分出来**：横竖判定优先用 EXIF 里的像素宽高；尼康 NEF 常把尺寸写在读不到的位置，这时退化看 EXIF 的旋转标记。两个都读不到（多为 EXIF 被后期工具重写过的 JPG）就归「尺寸未知」，可以在侧栏单独筛出来。退化判定没有宽高比，因此这一批照片里的方图会按旋转标记归到横或竖；有像素尺寸的照片不受影响。

**关了窗口去哪找 / 怎么彻底退出**：点 `×` 不退出，窗口收进系统托盘、应用继续在后台，切到别的软件后随时能回来。左键点托盘图标 = 显示主窗口，右键 = 「显示主窗口 / 退出 S·P」；macOS 也可用 ⌘Q。Windows 11 若没看到托盘图标，去任务栏「隐藏图标」溢出区找一下。再双击一次应用图标同样会把已开着的窗口唤回来。

**双击启动没反应**：启动阶段任何硬退出都会写进数据目录的 `startup-error.log`，下次启动成功自动删掉。三层兜底见 [`INTERNALS.md`](INTERNALS.md) 第 3 节。

**数据在哪**：macOS `~/Library/Application Support/SP/`，Windows `%APPDATA%\SP\`。删应用不会删照片，原片全程只读；重装后标记还在（按 `pair_key` 存，换盘、挪目录、重建索引都不丢）。

## 附：哪些事是自动的

S·P 的设计取向是「少让你点按钮」。下面这些都不需要你操心：

| 它自动做的 | 你的体验 |
|---|---|
| 选完文件夹就开扫 | 不用再点「扫描建索引」，边扫边出图 |
| 记住上次的图库 | 打开就在上次那批照片上，先用已有索引铺图（秒开），再后台补扫 |
| 启动时增量扫描 | 新拷进来的照片自动入库；文件没动过就不重排界面 |
| 滚动按需加载 | 滚到底自动续，几千张不用一次全读进内存 |
| 视口外释放位图 | 内存不随浏览张数增长，滚回来秒恢复 |
| 换文件夹切视图 | 旧照片的记录留着（标记能复用），但不再出现在界面上 |

这也是为什么「重新扫描」在绝大多数时候都不用点：正常情况下启动已经把新增补齐了。
